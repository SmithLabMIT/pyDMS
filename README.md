# pyDMS
### Python package for Dual Mode Sorption (DMS)

INSERT LOGO HERE

pyDMS computes the parameters for the dual mode sorption model (CITE DMS) using linear free energy relationship (LFER) and van't Hoff constraints.

### Features
- Compute reproducible DMS parameters: $C_H^\prime$, $k_D$, and $b$ via LFERs and van't Hoff constraints
- Easily access results for further python processing or output formatted report containing for external calculations
- Compute pure and mixed-gas sorption isotherms from the DMS parameters *with* error propogation
- Calculate ideal and mixed-gas sorption selectivities *with* error propogation and built-in multi-gas selectivity models
- Calculate fugacity from pressure via Virial and Peng-Robinson implementation
